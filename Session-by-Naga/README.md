## Service & Deployment Models

How much responsibility remains with the customer or the cloud provider.

### SAAS: Software As A Service:
Cloud provider manages most of the resources which includes Application, runtime, OS, Hardware. Eg: MS Teams, Outlook

### PAAS: Platform As A Service:
Aure provides the platform, developer only takes are of the business logic. Cloud manages, Runtime, OS, Hardware, Networking. Eg: Databricks, App Service

## SAAS v/s FAAS

### SAAS
Ready-to-use software app delivered entirely over the web. No installation or platform maintenance required.
Ex: Outlook, Azure Container Registry

### FAAS
Event-driven serverless code execution running only when triggered.
Zero charge when code is idle.
Ex: Azure Functions

## Cloud Deployment Models

### Hosting Environments:
- Private Cloud: Resources dedicated solely to one organiztion. Isolated on-premise or hosted infra.
- Public Cloud: Shared resources amongst organizations.
- Hybrid Cloud: Mix of private and public resources.

***

## CapEx v/s OpEx Cost Models

### Capital Expenditure:
- High upfront cost
- Fixed hardware capacity
- High risk of unutilized assets

### Operational Expenditure:
- Zero upfront cost, pay-as-you-go model
- Dynamic pay what you use approach, scales up/ down instantly
- No cost for unutilized assets
